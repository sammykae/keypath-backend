Downside Scenarios and Tenant Safety
This file clarifies risks and safeguards for tenants.

1. Property Value Declines
If token price decreases:
Tenant never owes money
Token value simply adjusts

2. Loss of Good Standing
If tenant falls out of Good Standing:
Unvested tokens may be forfeited
Vested tokens remain intact

3. Foreclosure
Tenants receive:
Value of vested tokens from any residual economic proceeds
No debt responsibility

4. Early Move-Out
Tenants may:
Cash out vested tokens
Forfeit unvested tokens
