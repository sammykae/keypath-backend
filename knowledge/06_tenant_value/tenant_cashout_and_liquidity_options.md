Tenant Cash-Out and Liquidity Options
Several pathways exist for tenants to realize value from tokens.

1. Move-Out Conversion
Vested tokens convert to cash at the last valuation price.

2. Tenant-Initiated Sale
Possible buyers:
Landlord (first option)
Approved investors
Marketplace participants

3. Liquidity Backstop
If no buyer exists, discounted liquidity is available.

4. Use Toward Purchase (Optional Scenario)
If landlord sells the property:
Tenant may apply vested token value to closing costs.
