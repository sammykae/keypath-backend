Tenant Equity Benefits
KeyPath provides tenants a structured method to build economic value without taking on ownership risk or mortgage obligations.

1. Transparent Equity Participation
Tenants clearly see:
How much economic value they earn
How value changes over time
Vesting progress

2. No Ownership Liability
Tenants avoid:
Mortgage responsibility
Maintenance burdens beyond standard lease
Property tax requirements

3. Portable Economic Value
When tenants move:
Vested tokens convert into cash value
Value can support relocation or down payment

4. Improved Financial Literacy
The dashboard helps tenants understand:
Equity accumulation
Annual valuation
Long-term financial impacts
