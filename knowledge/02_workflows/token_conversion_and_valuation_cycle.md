Token Conversion and Valuation Cycle

1. Token Creation
Tokens are created at onboarding based on:
Agreed property value
Landlord’s equity
Percentage allocated to tenant pool
Example:
Property value: $400,000
Landlord equity: $160,000
Pool: 20% → $32,000
Token count: 320 tokens
Token price: $100 each

2. Annual Valuation Inputs
Valuation methods include:
Appraisal
Broker Price Opinion
Automated Valuation Models (Zillow, Redfin, CoreLogic)
Blended weighted average

3. Updating Token Price
Formula:
New Token Price = Tenant Pool Value ÷ Total Tokens
Pool value adjusts with:
Property appreciation or depreciation
Amortization (landlord equity increases)
Only landlord equity can dilute landlord, not tenants

4. Adjusting Tenant Balances
After valuation:
Tenant token quantity stays the same
Token price updates
Dashboard shows new total value

5. Conversion at Exit
Tokens convert to cash at:
Move-out
Buyback
Marketplace liquidity event
