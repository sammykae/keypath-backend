Tenant Journey and Equity Flow
This file outlines the tenant experience from onboarding through exit.

1. Tenant Onboarding
Account Creation
Tenant provides:
Identity details (KYC)
Contact information
Bank account connection
Review of Token Plan
Dashboard shows:
Token earnings rules
Vesting thresholds
Annual valuation process
Cash-out options
Execution of Agreements
Tenant signs:
Standard lease (unchanged)
TEPA

2. Earning Tokens
Tenants earn tokens through several mechanisms:
On-time rent payments
Maintenance incentives
Lease renewals
Voluntary contributions
Spot payments (instant vesting)
Each earning action updates the tenant dashboard.

3. Vesting
Vested tokens remain permanently earned
Unvested tokens require Good Standing
Good Standing depends on:
Rent compliance
No major violations
No material damage

4. Annual Valuation
Each year, the token price updates based on property value.
Tenant dashboard automatically adjusts:
Equity balance
Unrealized gains/losses
Long-term projections

5. Exit
At move-out:
Vested tokens → paid out
Unvested tokens → revert
Tenant receives statement detailing:
Token quantity
Token value
Fees or adjustments
