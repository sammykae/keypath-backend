Full Ownership Conversion Event (Optional Scenario)
While KeyPath does not create a path to automatic homeownership, a landlord may choose to sell the property to a tenant.
This section describes how a voluntary sale interacts with tokens.

1. No Automatic Right to Purchase
TEPA does not grant tenant a purchase option
Purchase is at landlord discretion

2. Using Token Value in Purchase
If a sale occurs:
Tenant may use token value as part of down payment
Final valuation determines contribution amount

3. Clean Separation from Token Program
If tenant buys the property:
Tokens convert to cash value applied toward closing
TEPA terminates
Token engine deactivates
