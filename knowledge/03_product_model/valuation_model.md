Valuation Model

1. Inputs
Annual valuation uses:
Appraisal
Broker Price Opinion
Automated Valuation Model
Weighted blend of all three

2. Tenant Pool Recalculation
Tenant pool value =
(Updated Property Value × Pool Percentage)

3. Token Price Calculation
Token Price = Pool Value ÷ Total Tokens

4. Impact of Property Changes
Appreciation → higher token price
Depreciation → lower token price
Amortization → increases landlord equity; does not dilute tenant pool
